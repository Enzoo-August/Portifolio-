# 🌟 Portfólio — Enzo Augusto

Bem-vindo ao meu portfólio pessoal!  
Este site foi desenvolvido com **React**, **Vite** e **Tailwind CSS**, com o objetivo de apresentar meus principais projetos, habilidades técnicas e contatos profissionais.

---

## 💻 Tecnologias Utilizadas

- **React** — Biblioteca principal para construção da interface  
- **Vite** — Ferramenta moderna e rápida de build  
- **Tailwind CSS v4** — Estilização responsiva e moderna  
- **React Router DOM** — Gerenciamento de rotas e navegação  
- **React Icons** — Ícones personalizados  
- **LocalStorage** — Armazenamento do tema escuro/claro  

---

## 🌙 Funcionalidades

✅ **Tema Escuro/Claro** com persistência no `localStorage`  
✅ **Barra de Pesquisa** funcional nos projetos  
✅ **Rotas Dinâmicas** com exibição de detalhes individuais  
✅ **Formulário de Contato** que exibe os dados preenchidos em um `alert()`  
✅ **Animações e Microinterações** em botões, links e cards  
✅ **Design Responsivo** compatível com mobile e desktop  
✅ **Acessibilidade e SEO básico** com textos descritivos e `alt` nas imagens
