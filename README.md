  # 💼 Portfólio — Enzo Augusto

  Portfólio pessoal desenvolvido para apresentar meus projetos, habilidades e informações de contato de forma moderna, responsiva e interativa.  
  O site foi construído com **React + Tailwind CSS**, e possui modo **claro/escuro**, rotas dinâmicas e microinterações suaves.

  ## 🚀 Acesse o projeto

  🔗 **Site ao vivo:** [👉 https://portifolio-uhah.vercel.app/](https://portifolio-uhah.vercel.app/)  
📁 **Repositório GitHub:** [👉 https://github.com/Enzoo-August/Portifolio-](https://github.com/Enzoo-August/Portifolio-)

  ## 🧭 Estrutura do site

  - **Menu de navegação** — com alternância de tema (modo claro/escuro) e rotas configuradas com React Router.
  - **Página inicial** — apresentação pessoal com botões de acesso rápido.
  - **Lista de projetos** — com barra de pesquisa que filtra conforme o usuário digita.  
    - Se nenhum projeto for encontrado, aparece a mensagem *“Nenhum projeto localizado”*.
  - **Página de detalhes** — rotas dinâmicas mostram descrição, tecnologias e link do projeto.
  - **Página “Sobre”** — informações pessoais, formação, idiomas e skills.
  - **Página “Contato”** — formulário funcional que exibe os dados preenchidos em um `alert()` e links diretos para redes sociais.
  - **Rodapé (Footer)** — ícones interativos com links para LinkedIn e GitHub.

  ---

  ## 🛠️ Tecnologias utilizadas

  - **React.js** — construção dos componentes e rotas  
  - **React Router DOM** — navegação SPA (Single Page Application)  
  - **Tailwind CSS v4** — estilização moderna e responsiva  
  - **React Icons** — ícones (LinkedIn, GitHub, Email, Telefone, etc.)  
  - **Vite** — ferramenta de build e ambiente de desenvolvimento  
  - **JavaScript (ES6+)** — lógica e interatividade  
  - **Google Fonts (Poppins)** — tipografia padrão do site  

  ---

  ## 🧠 Conceitos aplicados

  - **Props e rotas dinâmicas**
  - **Renderização condicional**
  - **Tema claro/escuro com persistência via `localStorage`**
  - **Responsividade (Mobile First)**
  - **Acessibilidade (alt em todas as imagens)**
  - **SEO básico (títulos e descrições semânticas)**
  - **Microinterações** (transições e animações suaves em botões, cards e links)
